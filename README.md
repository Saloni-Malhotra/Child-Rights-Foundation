# Child Rights Foundation

A fully responsive, modern, and accessible website built for **Child Rights Foundation (CRF)**, a non-profit organization working to support, protect, and empower underprivileged children through education, health support, and community programs.

This project aims to:
- Improve CRF’s **digital presence**
- Create a **clear, trustworthy platform** for donors and volunteers
- Make CRF’s programs and impact more visible
- Enable **volunteer onboarding** and **donation flow** through a simple UI

---

## Tech Stack

**Frontend Framework:** React + TypeScript  
**Bundler:** Vite  
**Styling:** Tailwind CSS  
**Assets:** Custom icons, images, and responsive components  
**Deployment:** GitHub Pages / Netlify / Vercel (choose any)

---

## Features

### **Home Page**
- Hero section with mission statement  
- Smooth scroll animations  
- Quick links to programs, gallery, and volunteering

### **Programs Page**
Showcases CRF’s major initiatives:
- Education support  
- Medical and nutrition camps  
- Community childcare  
- Awareness workshops  

### **Gallery Page**
A curated collection of photos from past events and child welfare activities.

### **Donate Page**
Clear pathways for donors to contribute:
- QR code donations  
- Bank transfer details  
- Upcoming online payment integration  

### **Volunteer / Get Involved Page**
Encourages youth participation with:
- Simple steps to register  
- Types of volunteering activities  
- Contact support  

### **Contact Page**
Includes:
- Email  
- Phone  
- Address  
- Social media
